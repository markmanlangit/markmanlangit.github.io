Internal concern reports that log themselves

Workflow automation, 2026

Every internal concern (IC) arrives as an email with a link to a PDF report. Each one had to be opened, read and typed into the monitoring log by hand, which was slow and easy to get wrong.

I built an n8n workflow that watches a dedicated intake folder on the company mail server and does the encoding itself, from the email to a finished row in the log.

What changed

  • Live in production since September 2026, processing real reports
  • New ICs no longer need manual encoding
  • Every row links to its source PDF, so any figure can be traced back
  • Only emails from approved senders reach the workflow

A dashboard whose totals hold up

Excel data model and dashboard, FY2025–2026

The FY2025–2026 IC Monitoring Log feeds a formula-driven data model and a chart dashboard. Management sees IC count and cost impact by department, status and month, and the charts follow the log as it changes.

Raw totals were misleading, so I set clear rules for what counts:

  1. Cancelled and customer-care cases stay in the log, but don't count toward total ICs or cost impact.
  2. Jobs from a separate job-number series aren't internal concerns, so they're kept out entirely.
  3. Rows filed under Others or Pending are left off the department charts.
